# Control de Ventas

Esta es una aplicación web ligera para registrar y revisar ventas diarias. Funciona completamente en el navegador y guarda la información en `localStorage`.

## ¿Qué puedes hacer?

- Registrar ventas con fecha, producto, canal, unidades, precio y costo.
- Visualizar totales, unidades y ticket promedio.
- Filtrar por canal y buscar por texto.
- Eliminar registros individuales o limpiar todo.

## Uso rápido

1. Abre `sales-app/index.html` en tu navegador.
2. Registra una venta con el formulario.
3. Revisa la tabla y los indicadores superiores.
